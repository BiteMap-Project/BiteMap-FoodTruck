# SCRUM-38: Create Seed and Demo Data

### Objective:
Prepare sample data for the BiteMap Food Truck application so its main features can be demonstrated and tested consistently.

### Planned Tasks:

1. Create sample food truck records with names, food categories, and locations.

2. Add sample menu items with descriptions and prices for each food truck.

3. Ensure each menu item is associated with the correct food truck.

4. Provide enough sample data to test food truck discovery and menu browsing.

5. Verify that the sample data appears correctly on the visitor page and can support the Sprint 1 demonstration.

6. Document how the sample data is loaded or prepared for testing.

### Expected Result: 
The application has consistent sample food trucks and menu items available for demonstrations and testing. Users can discover different trucks, view their menus, and select items from the appropriate truck.

### Acceptance Criteria:

- Multiple sample food trucks are available.

- Each truck has identifiable information and menu items.

- Menu items display their names and prices.

- Each menu item belongs to the correct truck.

- The sample data supports testing the food truck discovery workflow.

- The setup instructions explain how to prepare the data for a demonstration.
